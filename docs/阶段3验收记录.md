## 实机与浏览器检查

- Windows Electron 主窗能够显示、隐藏到托盘并恢复。提示词模式能安装、释放和重新安装原生鼠标钩子。通过托盘退出后，观测到的 14 个进程全部退出，后端端口可重新绑定。托盘操作通过其已注册回调触发。
- 使用真实 Realtek 系统回环和麦克风同时采集。连续启停两轮后均可重新打开设备，重复占用均被拒绝。另用低音量 997 Hz 测试音验证两轮回环信号，每轮收到 8,192 个回环采样和 8,208 个麦克风采样。验收只保留计数和频率检测结果。
- Chromium 使用手机视口从普通 HTTP 域名加载生产构建，实测 `isSecureContext` 为假且 `crypto.randomUUID` 不可用。两条同名待办生成不同 ID，一次保存成功，刷新后可从模拟后端重载。
- 最后一轮 Windows Playwright 复跑中，测试工作进程结束后，执行器仍在等待 Vite 预览服务退出。关闭本轮专用预览进程后，执行器以状态码 0 输出上述结果。
